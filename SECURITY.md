# Security Policy

This repository holds the source of rustlogs.com. Report a vulnerability
in the website, or in the rlg library it describes, privately through
[GitHub's advisory form](https://github.com/sebastienrousseau/rlg/security/advisories/new)
or by the email address in the library's
[security policy](https://github.com/sebastienrousseau/rlg/security/policy).
Machine-readable disclosure metadata lives at
[`/.well-known/security.txt`](.well-known/security.txt) per
[RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).

Please do **not** open a public GitHub issue for a suspected security
vulnerability: report it privately first to coordinate disclosure.
